# TLA Maker

Créateur de tableaux de langage assisté (CAA), libre, pour Linux et Windows. Format natif : Open Board Format (`.obf` / `.obz`).

Dessins : © Gouvernement d'Aragon, auteur Sergio Palao, [ARASAAC](https://arasaac.org), licence CC BY-NC-SA — usage non commercial uniquement. Emojis : emojibase (MIT).

Build : `npm ci && npx tauri build`.
